# Customer-Churn-System
# 🔍 Customer Churn Prediction System

A full-stack machine learning application to predict customer churn using **Random Forest** and **XGBoost**, with a frontend built using **HTML** and a backend served through **Flask**.

---

## 📌 Objective

To help businesses identify customers likely to leave (churn) so they can take proactive steps to retain them.

---

## ⚙️ Technologies Used

### Backend:
- **Python 3.8+**
- **Flask** – Web framework
- **Pandas**, **NumPy** – Data handling
- **Scikit-learn** – Preprocessing, model building (Random Forest)
- **XGBoost** – Advanced gradient boosting model
- **joblib** – for saving and loading machine learning models efficiently 


### Frontend:
- **HTML/CSS** – User interface

### Others:
- **Matplotlib/Seaborn** – Optional for plotting/EDA
